The Vector Dot Product Equation

ALGORITHM v2.4
Vector Angle Score = cos(θ) = (D⃗ · H⃗) / (||D⃗|| · ||H⃗||)

Where D⃗ represents the truck’s destination vector, and H⃗ represents the vector from the truck’s current GPS coordinates to the forward pickup hub.

❌ cos(θ) < 0 (Backtracking Rejection)

When the dot product is negative, the hub lies behind the truck’s current highway milestone. Aggregators that rely on radius search would mistakenly match this vehicle; RoadSide’s vector engine rejects it immediately.

✓ cos(θ) ≥ 0.85 (Forward Intercept Lock)

When the dot product is positive and close to 1, the hub is situated directly ahead along the remaining highway corridor. Cargo can be staged with zero km carrier diversion.
